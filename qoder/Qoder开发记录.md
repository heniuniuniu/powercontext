# Qoder 开发记录

## 项目

资料整理助手 —— 面向学习/科研场景的个人资料库与周报草稿工具。
配合 seekdb（混合检索）与 PowerContext（跨会话记忆）使用。

## Qoder 参与的开发环节

| 环节 | Qoder 完成的工作 | 对应产物 |
| --- | --- | --- |
| 需求拆解 | 把「资料散、重复整理、周报费时」拆成导入、检索、记忆、周报四个模块，确定各自输入输出 | `README.md` 的「核心功能」与「技术分工」 |
| 页面编码 | 生成单页站点：痛点卡片、检索框、命中列表、记忆卡片、代码仓库链接，浅色主题且适配移动端 | `site/index.html`、`site/app.js` |
| 服务编码 | 生成 seekdb 混合检索 SQL、表结构与索引 DDL、PowerContext 读写封装、带 CORS 的 HTTP 服务 | `server/search.py` |
| 调试 | 修正后端未启动时前端直接报错的问题：改为自动回退到内置示例数据；修正标签权重在刷新后丢失的问题：写入 localStorage 并在下次检索时读取 | `site/app.js` 的 `readMemo` / `writeMemo` |
| 验证 | 编排「导入 → 检索 → 记忆复用 → 周报」的验证步骤与重置方法 | `验证样例.md` |
| 发布 | 通过 Sites 发布项目网站，并把可见范围设为「任何人都可访问」 | 项目网站网址（提交平台时填写 `workUrl`） |

## 账号 UID

Qoder 账号 UID 用于核对站点归属与使用记录，由账号本人在 Qoder 个人中心复制后
填入大赛提交入口；本仓库不预置他人账号标识，也不包含任何真实凭据。

## 对话截图

需附关键开发环节的 Qoder 对话截图或录屏，由账号本人从 Qoder 会话中导出，
放在 `qoder/screenshots/` 目录后一并提交。仓库中只保留文字版过程记录，
不以文字记录冒充截图。

## 说明

项目主要开发工作在 Qoder 中完成，Sites 仅用于发布展示网站；
核心检索能力由 seekdb 承担，跨会话记忆由 PowerContext 承担，两者都在
验证样例中有可核对的读写记录。
