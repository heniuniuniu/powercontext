资料整理助手

Qoder × PowerContext × seekdb

别再翻十几个文件找一段笔记

把论文、课程笔记、会议记录导进 seekdb，用向量 + 全文 + 标签一次查到出处；
PowerContext 记住你最近在忙什么，下次打开直接接着上次的上下文。

解决的问题

资料散笔记、论文、聊天记录分散在不同目录，关键词记不清就找不到。
重复整理同一份资料在项目 A 和项目 B 里被各整理一遍。
周报费时每周要从聊天记录里手工拼出做过什么。

核心功能（可直接体验）

#1 notes/seekdb-week3.md · 数据库 · 相关度 4
向量索引刷新：新写入的文档需要刷新向量索引后才能被近邻检索命中，全文索引同理。
#2 papers/hybrid-retrieval.md · 检索 · 相关度 3
混合检索融合排序：seekdb 在同一条 SQL 里计算向量距离与全文相关性，用 RRF 融合两路排名。
#3 notes/powercontext.md · 记忆 · 相关度 2
PowerContext 保存任务进展与历史互动，模块重启后可以读取并用于下一轮上下文。

运行与自检（两种模式）

方式一：零依赖自检。cd qoder && python main.py 打印 SELFCHECK PASS 并以 0 退出；python main.py --serve 启动站点与 API（http://127.0.0.1:8899/）。未启动外部服务时使用内置语料 + 本地 memory.json。 

# 方式二：接入官方 PowerContext 1.5.1（SQLite 后端，已实测）
python -m venv .venv
.venv/Scripts/pip install "powercontext[server]"
.venv/Scripts/powercontext config init --template --output .env.powercontext
.venv/Scripts/powercontext server run --env-file .env.powercontext --port 8765

# 另开终端
POWERCONTEXT_URL=http://127.0.0.1:8765 .venv/Scripts/python main.py
# SELFCHECK PASS ...
# {"powercontext": "powercontext", "memory_backend": "powercontext", ...}

主流程：导入资料 → 向量 + 全文混合检索 → PowerContext Atomic Memory 记忆复用 → 周报草稿。配置 SEEKDB_DSN 时检索改走 seekdb 单条 SQL；PowerContext 不可达时自动降级回本地记忆。

技术分工

Qoder需求拆解、页面与检索服务编码、调试，以及通过 Sites 发布本项目网站。
seekdb存储切片原文与向量；一次 SQL 内完成向量近邻、全文匹配与标签过滤。
PowerContext官方 1.5.1 Atomic Memory：保存检索主题与常用标签，跨会话召回并影响排序权重。
