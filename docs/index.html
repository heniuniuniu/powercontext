资料整理助手

Qoder × PowerContext × seekdb

别再翻十几个文件找一段笔记

把论文、课程笔记、会议记录导进 seekdb，用向量 + 全文 + 标签一次查到出处；
PowerContext 记住你最近在忙什么，下次打开直接接着上次的上下文。

解决的问题

资料散笔记、论文、聊天记录分散在不同目录，关键词记不清就找不到。
重复整理同一份资料在项目 A 和项目 B 里被各整理一遍。
周报费时每周要从聊天记录里手工拼出做过什么。

核心功能（可直接体验）

#1 notes/seekdb-week3.md · 数据库 · 相关度 4
向量索引刷新：新写入的文档需要刷新向量索引后才能被近邻检索命中，全文索引同理。
#2 papers/hybrid-retrieval.md · 检索 · 相关度 3
混合检索融合排序：seekdb 在同一条 SQL 里计算向量距离与全文相关性，用 RRF 融合两路排名。
#3 notes/powercontext.md · 记忆 · 相关度 2
PowerContext 保存任务进展与历史互动，模块重启后可以读取并用于下一轮上下文。
PowerContext 记忆
最近主题：向量索引刷新
常用标签：数据库　该标签会在下一次检索中提升排序权重。
检索后端：内置示例数据（零依赖兜底，页面预渲染结果）

上面是主流程的真实输出（已预渲染，未执行脚本也能核对）；启动 python main.py --serve 后，同样的查询会走 seekdb 的混合检索 SQL， 并把本次主题写入 PowerContext。

运行与自检（零依赖）

cd qoder
python main.py
# SELFCHECK PASS: health / init / hybrid search / memory reuse / weekly report
# exit code 0
python main.py --serve      # 人工体验：http://127.0.0.1:8899/

主流程：导入资料 → 向量 + 全文混合检索 → PowerContext 记忆复用 → 周报草稿。 无需安装依赖、无需数据库、无需 API Key；配置 SEEKDB_DSN 与 POWERCONTEXT_URL 时自动切换为真实服务。

技术分工

Qoder需求拆解、页面与检索服务编码、调试，以及通过 Sites 发布本项目网站。
seekdb存储切片原文与向量；一次 SQL 内完成向量近邻、全文匹配与标签过滤。
PowerContext保存最近主题、常用标签与未完成任务，跨会话复用并影响排序权重。
